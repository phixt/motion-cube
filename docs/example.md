# 以下内容作为示例

用左手食指拨U举例。 以下按常规坐标讲解，所有角度都是从手指内侧（指腹侧）为标准计量的，也就是说手指略微弯曲大概是135度，完全伸直是180度，弯曲到极限可以成90度。

常规情况下，食指单拨U初始状态为近端指骨间关节自然弯曲，近端指骨间关节几乎不弯曲，第一指节和魔方一侧（UL边）几乎平行，第二和第三指节与魔方角（ULB的LB边）成约45度角，接触点落在指腹约近指尖1/3处。随后拨动，终态为左手食指指背和原ULB现ULF的L面贴合对齐，一部分延伸到现LU棱的L面，两个关节都弯曲，近端约45度，远端约135度。 单指常规两拨即上述复位后重复。 而双指（这里是食指和中指）连拨，初始态左手手掌旋转，食指和中指和U面近乎垂直，食指和中指两个关节自然弯曲，略成圆弧，食指指腹的靠中指侧1/3和ULB和LB边，或者准确说B面贴合，随后两个手指近似先后平行拨动，理想状态下拨动到一半手指即离开魔方，最终在近端自然放置。

而食指eido连拨，起手食指指腹贴合ULB的B面，角度可以成45度到完全平行U面。中间态类似食指单拨U的结束态。随后关节舒展，食指再推，最终态为食指近中指一侧贴合现UF边的F面，近端关节弯曲约135度，远端几乎不弯曲。
