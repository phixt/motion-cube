# start

我预计开发一个可以播放，编辑，查看，并具备基本魔方操控能力的魔方动作播放游戏。基底是一个基本的[三维三阶魔方](./base.md)，通过鼠标和键盘进行操控。不鼓励盲目遵循，因为我可能考虑不全，需要根据常规补全某些步骤或者系统。

## 动画功能

公式库: [公式库](./formula.md)
手法库：和公式强关联，但是可以单独编辑和使用。这里两者的逻辑请自行定夺，尽量高解耦，方便拓展和解决问题。
动画编辑器：支持魔方和手指的坐标高度定义，同时可以开启吸附使得编辑更方便。尽量根据起终位置自动解算路径，不过也要支持函数生成路径和关键帧等更细化的编辑。
手指手掌：高度从简，主要是模型上，比如用略有变形的圆柱体，不过要区分指腹指背等方向。
